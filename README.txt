Практическая работа №5 — Вариант 8: HSL ↔ Lab
Автор: [Купцов Арсений]
Тема: Преобразование цветовых пространств RGB → HSL → Lab с интерактивной коррекцией.


Описание:

Программа загружает изображение (PNG, JPEG, BMP), выполняет ручное преобразование RGB → HSL, позволяет интерактивно корректировать оттенок (Hue), насыщенность (Saturation) и яркость (Lightness) с помощью ползунков, а также демонстрирует промежуточное преобразование HSL ↔ Lab через RGB/XYZ.


Вариант 8

•	Полностью ручная реализация формул RGB ↔ HSL (без colorsys и аналогов).
•	Реализовано промежуточное преобразование RGB → XYZ → Lab и обратно.
•	Режим «Lab-шлюз»: после HSL-коррекции изображение можно пропустить через Lab-пространство (RGB→Lab→RGB) перед сохранением.
•	Отображение средних значений Lab и информации о пикселе под курсором (RGB, HSL, Lab).
•	Поддержка форматов: PNG, JPEG, BMP.



Требования

•	Python 3.8+
•	numpy
•	Pillow (PIL)
•	tkinter (обычно входит в стандартную поставку Python)



Запуск

pip install numpy pillow
python hsl_lab_editor_variant8.py

Использованные формулы
•	RGB ↔ HSL: алгоритм на основе Wikipedia (HSL and HSV) с адаптацией обратного преобразования через p/q (StackOverflow/NIWA).
•	RGB ↔ Lab: через промежуточное XYZ (D65, sRGB gamma).
